# Продуктовая книга Interlink

Публичная продуктовая книга Interlink для специалистов по управлению жизненным циклом изделия (PLM), инженерным системам (CAx), пользователей и продуктовых экспертов IPS.

Interlink исследует, как сохранить сильную инженерную семантику IPS — объекты и версии, состав, применяемость, изменения, точные конфигурации и производственные передачи — и реализовать её на более явном, расширяемом и производительном основании.

Книга отвечает на пять главных вопросов:

1. Какие задачи решает Interlink и почему проект появился?
2. Что сохраняется и что меняется относительно IPS?
3. Как именно будут работать пользователь, пакет изменения, подбор состава, модель данных и заказ?
4. Как планируется доказать функциональную эквивалентность?
5. Какие ответы и реальные примеры ещё нужны от продуктовых специалистов?

## Важная оговорка

Interlink находится в разработке. Книга различает:

- уже реализованный фундамент;
- принятые проектные решения;
- планируемые возможности;
- гипотезы, требующие испытаний;
- открытые вопросы, которые нельзя решать без опыта специалистов IPS и пользователей.

Документы не являются заявлением о готовом функциональном паритете с IPS.
