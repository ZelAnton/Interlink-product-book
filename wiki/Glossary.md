# Словарь

## Основные понятия

| Термин | Простое объяснение |
|---|---|
| Объект | Изделие, деталь, документ или другой предмет, сохраняющий тождество при появлении новых версий |
| Версия объекта | Определённое состояние объекта; рабочее либо зафиксированное |
| Рабочая версия | Ещё не выпущенное состояние внутри конкретного пакета изменения |
| Позиция состава | Конкретное место использования дочернего объекта в родительской версии |
| Пакет изменения | Согласованный набор рабочих версий и изменений состава, рассматриваемый как целое |
| Проведение изменения | Превращение согласованного рабочего результата в новые зафиксированные версии |
| Точная фиксация версии | Требование использовать строго указанную версию |
| Временное предпочтение | Временный выбор версии для текущей проработки без постоянной фиксации |
| Применяемость | Условия действия версии для изделия, серии, заводского номера или даты |
| Условия подбора | Полный явный набор исходных условий формирования состава |
| Правило подбора | Управляемое правило выбора одной допустимой версии |
| Резервный выбор | Явно разрешённое менее строгое поведение, если основной выбор не дал результата |
| Подходящая версия не найдена | Позиция нужна, но ни одна версия не удовлетворяет условиям |
| Основание выбора | Объяснение, почему выбрана конкретная версия |
| Назначенная основная версия | Версия, явно выбранная основной; она не обязана быть самой новой |
| Последняя допустимая версия | Самая новая среди версий, разрешённых в данном сценарии |
| Степень инженерной готовности | Предметный уровень готовности версии; не равен состоянию задания согласования |
| Условие включения позиции | Правило, определяющее, нужна ли позиция в выбранной комплектации |
| Неизменяемый снимок | Зафиксированное точное состояние полного состава для выпуска, заказа или обмена |
| Нить позиции | Устойчивая идентичность одного места в составе между версиями |
| Физический экземпляр | Конкретная изготовленная единица с серийной идентичностью |
| Партия | Группа изготовленных или поставленных единиц, прослеживаемая как целое |
| Фактический состав | Что действительно установлено в конкретном экземпляре |

## Близкие понятия, которые нельзя смешивать

### Позиция исключена и версия не найдена

Исключённая позиция не нужна в выбранной комплектации. При отсутствии версии позиция нужна, но система не смогла найти допустимое состояние компонента.

### Основная и последняя версия

Основную назначают. Последняя вычисляется по порядку версий и заданным ограничениям.

### Применяемость и готовность

Применяемость отвечает «для какого изделия, номера или периода». Готовность отвечает «до какого инженерного состояния дошла версия».

### Аналог и локальная замена

Глобальный аналог действует как допустимый другой объект предприятия. Локальная замена применяется внутри определённого состава и может заменять один набор позиций другим.

### Живой заказ и снимок передачи

Живой заказ может изменяться и пересчитываться. Снимок хранит точное состояние, официально переданное в конкретный момент.

### Инженерная версия и сервисный факт

Новая конструкция создаёт инженерную версию. Замена физического двигателя при обслуживании создаёт исторический факт фактического состава.
